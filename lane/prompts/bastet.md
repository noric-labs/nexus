The terminal runs Bastet, a Tetris clone (80x24). On the main menu, "Play! (normal
version)" is selected: press <Enter>. On "Get ready!" press <Space> to start. Keys: <Left>
and <Right> move the falling block, <Space> rotates it clockwise, <Up> rotates it
counterclockwise, <Down> moves it down one row (send several <Down> to drop it; <Enter>
does not drop). Place each block to complete full rows; keep the stack low and flat. When
the game ends, answer its prompts (type a name then <Enter>) and start again. Start by
calling screen().
